# Tarefa 09 — CONTECSI

## Modalidade proposta
**REX — Resumo Expandido, graduação.** O projeto está em fase de pesquisa e modelagem: há descrição arquitetural, diagramas e matriz de decisões, mas o repositório ainda não registra protótipo executável nem avaliação experimental. O REX permite apresentar esses resultados parciais sem alegar evidências que ainda não foram produzidas. A modalidade também exige que o primeiro autor seja estudante de graduação; confirmar elegibilidade com os orientadores antes da submissão.
