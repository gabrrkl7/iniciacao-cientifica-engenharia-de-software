# Artigos

Materiais preparados para publicação e revisão no III Congresso UniSENAI-SP de Educação, Tecnologia e Inovação.

## Resumo expandido

- `resumo-expandido.pdf`: arquivo para enviar aos orientadores e, após a revisão, submeter na plataforma do evento.
- `resumo-expandido.docx`: arquivo editável para incorporar correções.
- `resumo-expandido.md`: versão textual para controle e rastreabilidade.
- `resumo-expandido.html`: fonte usada na geração da versão editável e do PDF.

O trabalho está marcado como pesquisa em desenvolvimento. Resultados quantitativos de desempenho ainda não foram inventados; a validação experimental permanece como etapa posterior.
